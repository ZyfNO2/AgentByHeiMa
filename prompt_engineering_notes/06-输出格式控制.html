任务介绍：金融文本语义匹配

文本匹配任务是自然语言处理（NLP）中的核心任务之一：给定一段查询文本和一段候选文本，判断两者在语义上是否相似或匹配。

💡 为什么文本匹配很重要？
文本匹配是搜索引擎、推荐系统、智能客服、去重系统等应用的核心技术。 它不依赖关键词的字面匹配，而是理解两段文本的深层语义含义， 判断它们表达的是否是同一件事。这是大模型在 NLP 领域展现"理解能力"的关键场景。

提示词设计：Few-Shot 文本匹配

文本匹配的 Prompt 设计遵循与前面几集一致的 Few-Shot 模式，但任务形式有所不同：

💡 核心设计思路
与分类/抽取不同，文本匹配需要模型同时理解两段文本并做出二元判断。 我们通过 Few-Shot 示例展示"句子对 → 相似性判断"的模式，让模型学会这种推理方式。

Prompt 结构拆解

  • System Prompt：定义模型为"文本匹配专家"，明确任务是判断两个句子的语义相似性
  • Few-Shot 示例：提供若干组"句子一 + 句子二 → 是/不是"的示例对
  • 输入格式：每次传入一个待判断的文本对（sentence1, sentence2）
  • 输出格式：输出"是"或"不是"，并附带简短的匹配理由

System Prompt 设计要点

Prompt 设计 
你是一个文本匹配专家。请判断给出的两个句子是否语义相似。
如果相似回复"是"，如果不相似回复"不是"。参考下面的示例。

Few-Shot 示例设计

示例覆盖两种情况——语义相似 和 语义不相似 的金融文本对：

类型句子一句子二期望输出
相似 公司ABC发布了季度财报，显示盈利增长。 财报披露，公司ABC利润上升。 是
不相似 央行宣布降息以刺激经济。 某科技公司推出新款智能手机。 不是
💡 关键技巧总结
  • 示例要覆盖所有输出类别（是 / 不是），避免模型偏向某一种回答
  • 示例中的文本应来自同一领域（金融），保持上下文一致性
  • 每对示例的相似度梯度要合理，便于模型学习判别边界

完整代码：09_Text_Matching_FewShot.py

以下是视频课程中展示的完整代码，实现基于 Few-Shot 的金融文本语义匹配任务：

Python 
import os
from dotenv import load_dotenv
from openai import OpenAI


def main():
    """
    文本匹配任务 - Few-Shot 学习示例：
    1. 使用 Few-Shot 方式让模型理解文本匹配任务
    2. 判断两个金融文本句子是否语义相似
    3. 输出 "是" 或 "不是"
    """
    load_dotenv()

    client = OpenAI(
        api_key=os.getenv("API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    )

    examples_data = [
        {
            "sentence1": "公司ABC发布了季度财报，显示盈利增长。",
            "sentence2": "财报披露，公司ABC利润上升。",
            "answer": "是"
        },
        {
            "sentence1": "央行宣布降息以刺激经济。",
            "sentence2": "某科技公司推出新款智能手机。",
            "answer": "不是"
        },
        {
            "sentence1": "股市今日大幅震荡，投资者情绪谨慎。",
            "sentence2": "今天股票市场波动剧烈，投资人态度趋于保守。",
            "answer": "是"
        }
    ]

    questions = [
        {
            "sentence1": "传智教育A股今日收盘价68元人民币。",
            "sentence2": "传智教育股票今天以68块钱收市。"
        },
        {
            "sentence1": "美联储维持基准利率不变。",
            "sentence2": "北京今天天气晴朗，气温适宜。"
        }
    ]

    messages = []

    messages.append({
        "role": "system",
        "content": "你是一个文本匹配专家。请判断给出的两个句子是否语义相似。"
                   "如果相似回复'是'，如果不相似回复'不是'。参考下面的示例。"
    })

    for example in examples_data:
        messages.append({
            "role": "user",
            "content": f"句子一:{example['sentence1']}\n句子二:{example['sentence2']}"
        })
        messages.append({
            "role": "assistant",
            "content": example["answer"]
        })

    print("=" * 80)
    print("文本匹配任务 - Few-Shot 学习示例")
    print("=" * 80)
    print(f"\nFew-Shot 示例数量: {len(examples_data)}")
    print(f"待匹配的问题数量: {len(questions)}")
    print("\n" + "-" * 80)

    for i, q in enumerate(questions, 1):
        print(f"\n【问题 {i}】")
        print(f"句子一: {q['sentence1']}")
        print(f"句子二: {q['sentence2']}")
        print("\n匹配结果:")

        current_messages = messages + [{
            "role": "user",
            "content": f"句子一:{q['sentence1']}\n句子二:{q['sentence2']}"
        }]

        response = client.chat.completions.create(
            model="qwen3-max",
            messages=current_messages
        )

        result = response.choices[0].message.content
        print(result)
        print("-" * 80)

    print("\n" + "=" * 80)
    print("任务完成！提示词工程系列全部结束！")
    print("=" * 80)


if __name__ == "__main__":
    main()
💡 代码结构解析
  • examples_data：定义 3 组 Few-Shot 示例（2 组相似 + 1 组不相似），每组包含 sentence1、sentence2、answer
  • questions：定义 2 组待测试的文本对
  • messages 构建：system prompt → 3 组 few-shot 示例（交替 user/assistant）→ 实际问题
  • 调用 qwen3-max：通过阿里云 DashScope 兼容 OpenAI 接口调用
  • 输出：直接打印模型的匹配判断结果

💡 结果分析

  • 这证明了 Few-Shot 方法在零训练成本的前提下，可以让大模型有效完成细粒度的语义理解任务
