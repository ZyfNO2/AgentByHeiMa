案例介绍：金融领域的三大业务场景

当前处于金融领域信息化发展时代，金融数据大量激增。许多投资者和研究者试图通过对这些数据进行深度分析来获得有效的决策辅助，尽可能减少决策失误带来的损失。 因此，针对金融数据的分析方法研究是目前十分有益且热门的话题。

三大业务场景

本课程围绕以下三个核心业务场景展开提示词工程实践：

📊 场景一：金融文本分类
对金融文本进行类别判定，如区分新闻报道、公司公告、财务公告、分析师报告
📄 场景二：金融文本信息抽取
从非结构化金融文本中提取结构化字段，如日期、股票名称、开盘价、收盘价、成交量等
🔗 场景三：金融文本匹配
判断两段金融文本之间的语义关联度或匹配关系，用于信息检索、去重等任务

技术选型与方法论

技术方案总览
  • 大模型选择：Qwen 在线大模型（阿里云通义千问 qwen3-max）
  • 核心方法：基于 Few-Shot + Zero-Shot 的思想设计 Prompt（提示词）
  • 实现方式：通过精心设计的提示词，让大模型直接完成上述三类金融 NLP 任务，无需微调
  • 调用接口：使用 OpenAI 兼容 SDK 调用阿里云 DashScope API
核心思路
本课程的核心理念是：一个好的提示词，甚至能让基础模型的输出效果媲美经过简单微调的模型。 不管是 RAG 还是 Agent 智能体亦或是其它围绕模型的各类复杂的开发工作，本质上都可以简单总结为在提示词上下功夫。 提示词优化是所有大模型应用开发的基础必修课。
02

Zero-Shot 零样本思想

Zero-shot Learning（零样本学习）是指在训练阶段不存在与测试阶段完全相同的类别， 但是模型可以使用训练过的知识来推广到测试集中的新类别上。 这种能力被称为「零样本」学习——因为模型在训练时从未见过测试集中的新类别。 这个概念在模型训练和提示词优化两个层面均有体现。

在模型训练中：属性迁移推理

🐕 训练层面 · 属性迁移
已知马（四脚兽）、虎（有条纹）、熊猫（黑白色）的特征， 但模型未训练过斑马的数据（不认识斑马）。此时告知模型： 「斑马是四脚兽 + 有黑白色的条纹」， 模型即可利用已知数据中的属性关联进行推理，从而识别出斑马。
推理链路：
训练数据: 马(四脚兽) / 虎(有条纹) / 熊猫(黑白色)
↓
新输入: 斑马 = 四脚兽 + 黑白色条纹
↓
→ 模型通过属性组合推理识别出「斑马」

在提示词优化中：用语言定义任务

📝 提示词层面 · 语言驱动
Zero-shot 思想用于基于已训练的能力，不提供任何示例， 仅通过语言去描述任务的要求、目标和约束，让模型直接生成结果。

一言以蔽之：「用语言定义任务，解放（信任）模型的预训练知识」

Zero-Shot 实战示例：情感判断

Zero-Shot Prompt 示例 — 情感倾向判断 
# Zero-Shot：不提供示例，仅通过语言描述任务要求
"""请判断以下用户评论的情感倾向，输出 正面 或 负面。

这款代餐鸡胸肉饱腹感很强，吃起来也不柴，很推荐！"""

# 模型直接基于预训练知识进行推理并输出：
# → 正面
Zero-Shot 的关键特点
  • 无示例依赖：不需要提供任何输入-输出示例对，纯靠自然语言指令驱动
  • 依赖预训练知识：模型输出的质量取决于其在预训练阶段是否学到了相关任务的隐式模式
  • Token 成本低：Prompt 只包含指令本身，没有额外的示例内容占用 Token
  • 适用范围广：适合通用任务（翻译、摘要、简单分类等），但对复杂或特定格式任务可能不够稳定
03

Few-Shot 少样本思想

Few-shot Learning（少样本学习）是指当模型在学习了一定类别的大量数据后， 对于新的类别，只需要少量的样本就能快速学习。 对应的还有 One-shot Learning（单样本学习），即样本少到只有 1 个的情况，也算 Few-Shot Learning 的一种特例。

在模型训练中：相似度判断方法

🐕 训练层面 · 相似度泛化
基于少量企鹅样本并结合相似度判断方法， 推论未知图片内含「企鹅」。即模型不需要大量企鹅数据，只需几个样本就能学会识别新类别的模式。
推理链路：
已有知识: 大量动物图像（包含各类特征模式）
↓
提供: 少量企鹅样本图片（如 3~5 张）
↓
→ 通过相似度匹配，推论未知图片 = 企鹅

在提示词优化中：用示例定义任务

📝 提示词层面 · 示例引导
Few-shot 主要用于基于少量示例，让模型参考示例回答。

一言以蔽之：「用示例定义任务，在模型的预训练知识的基础上，提升模型回答的对齐精度」

示例的作用是帮助模型理解期望的输出格式、风格和深度，而不仅仅是任务本身。

Few-Shot 完整实战示例：产品信息抽取

以下是一个完整的 Few-Shot 信息抽取示例，从产品描述文本中提取「产品名称」和「核心卖点」两个字段，以 JSON 格式输出：

Few-Shot Prompt 示例 — 产品信息抽取 
请抽取产品名称和核心卖点 2 个字段，格式为 Json，我提供 2 个示例。

示例1：MacBookPro高效节能，性能强大，适合牛马工作使用
输出：{"产品名称": "MacBookPro", "产品卖点": "高效节能，性能强大"}

示例2：联想笔记本拥有RTX4060独立显卡，畅玩游戏，丝滑流畅
输出：{"产品名称": "联想笔记本", "产品卖点": "畅玩游戏，丝滑流畅"}

请处理：华为MatepadPro，高清大屏，长效续航，你的好帮手。"""

# 模型参考前 2 个示例的格式，对第 3 个输入进行抽取：
# → {"产品名称": "华为MatepadPro", "产品卖点": "高清大屏，长效续航"}
Few-Shot 示例的设计要点
  • 示例数量：通常 1~5 个即可，过多会浪费 Token 且边际收益递减
  • 示例质量：比数量更重要！示例必须准确反映你期望的输出格式和风格
  • 示例多样性：覆盖不同情况（如不同长度、不同难度），避免模型过拟合单一模式
  • 示例顺序：将最典型、最重要的示例放在前面，最后放待处理的输入
  • In-Context Learning：Few-Shot 的本质不是「训练」，而是通过上下文示例引导模型定位正确的输出模式
04

总结对比：Zero-Shot vs Few-Shot

Zero-Shot 和 Few-Shot 是提示词工程的两大核心范式。 它们在模型训练层面和提示词优化层面有着不同的含义和应用方式。 理清两者的区别与联系，是选择正确提示策略的关键。

双维度对比表

对比维度 Zero-Shot 零样本 Few-Shot 少样本
训练层面含义 基于已训练的属性/语义关联，迁移到未知的新类别（如：已知马/虎/熊猫 → 推理识别斑马） 基于少量样本 + 相似度判断，快速泛化识别新样本（如：几张企鹅图 → 识别未知企鹅）
提示词层面含义 不提供示例，仅用语言描述任务要求，依赖模型预训练知识直接生成结果 给模型少量示例，引导模型对齐示例的输出格式与风格
核心机制 「用语言定义任务，解放（信任）模型的预训练知识」 「用示例定义任务，提升模型回答的对齐精度」
是否需要示例 否 — 纯自然语言指令 是 — 需要 1~5 个输入-输出示例对
Token 成本 低 — 仅指令本身的 Token 较高 — 指令 + 所有示例的 Token
输出稳定性 中等 — 依赖指令质量和预训练覆盖度 高 — 示例约束了输出格式和风格
适用场景 通用任务（翻译/摘要/简单分类/常识问答） 特定格式输出/领域分类/复杂推理/风格迁移
典型用法 "将以下中文翻译成英文：{text}" "参考以下示例... 例1:→输出 例2:→输出 请处理:{text}"

如何选择？经验法则

✅ 优先使用 Zero-Shot
文本翻译 · 摘要生成 · 常识问答 · 简单情感分类 · 格式转换
⚡ 升级到 Few-Shot
特定领域分类 · 非 JSON 标准输出 · 风格化改写 · 边界情况处理
💡 进阶组合
CoT + Few-Shot 用于数学推理 · 多步逻辑推演 · 复杂决策链
📋 经验法则
先试 Zero-Shot → 效果不够再叠加 Few-Shot → 还不够加 CoT
