1 课程定位与目标

本课程是2026 年最新版的 LangChain + LangGraph 开发实战教程，由黑马程序员出品。它不是一门简单的 API 调用教程，而是一套从 AI 基础理论到企业级项目落地的完整学习体系。无论你是刚接触 AI 的初开发者，还是希望系统化掌握 LLM 应用工程化的工程师，这门课程都能为你提供清晰的学习路径和可落地的实战经验。

💡
一句话定位：这是一门以「AI 私厨」完整项目为载体，从零教你用 Python + LangChain + LangGraph 构建生产级 AI Agent 应用的系统课程。涵盖 AI 通识、框架原理、核心模块、工程实践四大维度。

在当前 AI 应用爆发式增长的时代背景下，单纯调用 OpenAI API 已经无法满足复杂业务需求。LangChain 作为目前最主流的 LLM 应用开发框架，提供了组件化、可组合的架构能力；LangGraph 则在此基础上引入有向图编排引擎，让 Agent 具备真正的自主决策和多步推理能力。本课程将带你完整走通这条技术路线。

3 学习路线图

整个课程按照「基础铺垫 → 框架入门 → 核心模块 → 项目实战」的递进式结构设计，共分为三大阶段：

第 1 章 AI 通识与基础 P00 ~ P12
从 AI 的定义与发展历程出发，理解人工智能的核心概念、神经网络的运作原理、大语言模型（LLM）的技术演进。这一阶段的目标是建立扎实的理论基础，让你不仅知道「怎么用」，更能理解「为什么这样设计」。涵盖内容：AI 三大流派、感知机与反向传播、Transformer 架构、主流 LLM 对比、Prompt Engineering 基础等。
第 2 章 LangChain 入门到精通 P13 ~ P27
进入 LangChain 框架的核心模块体系：Model 初始化与调用、Message 消息类型体系、Prompt 提示词工程、Tools 工具集成、Memory 记忆管理策略。通过「AI 私厨」这一贯穿全程的实战项目，将各模块知识点串联成完整的 Agent 应用。最终完成服务端搭建、OSS 对接、LangSmith 集成等生产级能力建设。
后续预告 进阶专题（规划中） P28+
在掌握基础之后，课程计划延伸至以下进阶方向：Agent 进阶（Multi-Agent 协作、Tool-use 优化）、Agentic RAG（自适应检索策略、查询改写、Hybrid Search）、LangGraph 深度实践（状态机设计、Human-in-the-Loop、Checkpoint 持久化）、以及生产部署最佳实践（评估体系、成本优化、安全防护）。

4 目标受众与前置要求

适合谁学？

  • 💻
    Python 后端开发者 希望转型或拓展 AI 应用开发能力的工程师，具备 Python 基础即可快速上手
  • 🤖
    AI/ML 初学者 对大模型应用感兴趣但缺乏系统工程化指导的学生或自学者
  • 📖
    全栈 / 产品技术人员 需要 AI 能力赋能现有产品的技术负责人或独立开发者
  • 🚀
    求职 / 转行者 目标岗位为 AI 应用开发工程师、Agent 工程师、LLM 应用架构师

前置知识要求

知识领域要求级别具体说明
Python 编程 基础必备 熟悉基本语法、函数、类、装饰器、虚拟环境（venv/conda）。不需要 ML 经验。
HTTP / API 了解即可 理解 RESTful API 概念、JSON 数据格式、Request/Response 模型。
命令行操作 基础必备 能使用终端执行 pip install、python 运行脚本、基本的文件操作。
机器学习 / 深度学习 非必须 第 1 章会从零讲解 AI 基础概念，有 ML 背景者可快速跳过。
前端开发 非必须 仅最后部署章节涉及少量前端概念，不影响主体学习。
