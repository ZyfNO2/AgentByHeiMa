1 LangSmith 平台概览

LangSmith 是 LangChain 官方推出的 LLM 应用开发平台，专注于解决大模型应用开发中的「黑盒问题」 —— 当 Agent 行为不符合预期时，你需要的不是猜测，而是精确的运行数据。

📊

Tracing（追踪）

完整记录每次 LLM 调用的输入/输出/延迟/Token 消耗

📰

Evaluation（评估）

自动化测试框架，批量评估 Prompt 和输出质量

📝

Prompt Hub

Prompt 版本管理、A/B 测试与协作编辑

📈

Monitoring

生产环境监控告警、用户反馈追踪

💡

为什么需要 LangSmith？

传统软件可以通过断点调试定位问题，但 LLM 应用是概率性的 —— 同样的输入可能产生不同的输出。LangSmith 通过 Trace 数据让你能「回放」每次运行过程，精确定位是哪一步出了问题。

2 环境变量配置

接入 LangSmith 只需要配置三个核心环境变量。打开你的 .env 文件：

.env — LangSmith 环境变量 
# ============================================
# LangSmith 配置 — 必填项
# ============================================

# 你的 LangSmith API Key（从 smith.langchain.com 获取）
LANGCHAIN_API_KEY="lsv2_pt_xxxxxxxxxxxxxxxxxxxx"

# Tracing 开关：设为 "true" 启用追踪
LANGCHAIN_TRACING="true"

# 项目名称：用于在 Dashboard 中区分不同项目
LANGCHAIN_PROJECT="ai-personal-chef"

# ============================================
# 可选配置项
# ============================================

# LangSmith 服务端点（国内用户通常不需要改）
# LANGCHAIN_ENDPOINT="https://api.smith.langchain.com"

# 是否在控制台打印 Trace 信息（调试时有用）
LANGCHAIN_VERBOSE="true"

  1. 注册 LangSmith 账号

    访问 smith.langchain.com，使用 GitHub / Google 账号登录即可免费使用。

  2. 获取 API Key

    进入 Settings → API Keys → Create new key。新账号有免费的 Trace 额度。

  3. 添加到 .env 文件

    将上述三个变量写入项目根目录的 .env，确保不要提交到 Git。

  4. 验证连接

    运行任意一次 Agent 调用后，刷新 LangSmith Dashboard 即可看到 Trace 记录。

⚠️

安全提醒

LANGCHAIN_API_KEY 类似于数据库密码，绝对不能硬编码在代码中或提交到公开仓库。务必使用 .env 文件 + .gitignore 保护敏感信息。

4 Prompt 版本管理与 A/B 测试

LangSmith 的 Prompt Hub 功能让你可以像管理代码一样管理 Prompt，支持版本对比和 A/B 测试：

Python — 使用 Hub 管理版本化 Prompt 
from langchain_core.prompts import ChatPromptTemplate
from langsmith import Client

# 初始化 LangSmith 客户端
client = Client()

# 方式一：推送 Prompt 到 Hub 进行版本化管理
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一名私人厨师..."),
    ("human", "{input}")
])

client.push_prompt(
    owner_id="your-org",
    prompt_name="personal-chef-v1",
    prompt=prompt,
    tags=["production", "chef-agent"],
    description="AI 私厨 v1.0 — 基础版 System Prompt"
)

# 方式二：从 Hub 拉取指定版本的 Prompt
retrieved_prompt = client.pull_prompt(
    owner_id="your-org",
    prompt_name="personal-chef-v1",
    label="prod"  # 使用 prod 标签的最新版
)
💡

A/B 测试最佳实践

创建两个版本的 Prompt（如 v1-简洁版 vs v2-详细版），在 LangSmith 中通过 Dataset + Evaluation 自动跑分对比。关注指标包括：回答准确率、Token 效率（质量/成本比）、用户满意度评分。

总耗时 ~3s | Tavily Search 占比最高，是主要优化目标

瓶颈类型 表现症状 优化方案
搜索 API 过慢 Tavily 调用耗时 > 1s 减少 max_results；启用缓存；考虑本地检索方案
多模态推理慢 VL 模型首次调用 > 2s 切换更快的 VL 模型；图片压缩预处理
ReAct 循环过多 Agent 反复调用同一工具 > 3 次 优化 System Prompt；增加 max_iterations 限制
Context 过长 单次调用 Token > 4000 启用摘要记忆；清理冗余历史消息
✅

优化成果参考

经过上述优化后，AI 私厨的平均响应时间从 3.2s 降至 1.8s，同时 Token 消耗减少约 35%。关键改进：(1) Tavily 结果缓存；(2) 图片压缩至 512px；(3) ReAct 最大迭代次数限制为 5。
