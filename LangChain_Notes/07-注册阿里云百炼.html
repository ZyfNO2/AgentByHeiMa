注册 阿里云百炼

全面了解阿里云百炼平台的核心功能与生态优势，完成账号注册、API Key 创建，掌握三种 API 调用方式，并通过三平台对比表做出最优选择。

时长 07:10 实操篇 平台注册

1 阿里云百炼平台介绍

阿里云百炼（Bailian）是阿里云推出的一站式 AI 开发平台。不同于 DeepSeek 这类单一模型服务商，百炼更像是一个「AI 模型超市 + 开发工具箱」——它聚合了国内外主流大模型，并提供从 API 调用到微调训练的完整工具链。

🌟
百炼的核心理念：「让 AI 开发像搭积木一样简单」。你不需要自己部署模型、不需要管理 GPU 集群、不需要处理复杂的推理优化——百炼把这些基础设施层全部抽象掉了，开发者只需专注于业务逻辑和 Prompt 设计。

平台核心优势

📚
多模型聚合
集成通义千问（Qwen）、DeepSeek、Llama、GLM 等国内外主流模型，一个 Key 调用全部
🛠️
全流程工具
API 调用、Prompt 模板、模型微调（SFT）、RLHF 训练、效果评估一站式完成
🌐
企业级保障
依托阿里云基础设施，提供 SLA 保障、数据安全合规、私有化部署选项
💰
灵活计费
新用户免费额度充足，按量付费透明可控，支持包年包月优惠方案
🚀
应用中心
内置对话机器人、智能搜索、文档问答等模板应用，零代码快速创建 AI 应用
🤖
LangChain 友好
官方支持 OpenAI 兼容接口和 DashScope SDK，与 LangChain 无缝集成
💡
通义千问（Qwen）系列：百炼平台上最核心的模型家族是阿里的自研 Qwen（通义千问） 系列，包含 Qwen-Turbo（极速版）、Qwen-Plus（增强版）、Qwen-Max（旗舰版），以及最新的 Qwen2.5 开源版本。在中文理解和生成能力上表现卓越。

2 账号注册步骤

百炼基于阿里云体系，注册流程需要先有阿里云账号。以下是完整步骤：

1
访问百炼控制台
打开浏览器访问阿里云百炼平台的官方网站。
平台地址：https://bailian.console.aliyun.com/
如果还没有阿里云账号，会自动跳转到注册页面。
已有阿里云账号可直接登录后进入百炼控制台。
2
使用阿里云账号登录 / 注册
百炼使用统一的阿里云账号体系。支持多种登录方式：
推荐方式：阿里云账号 + 密码登录 或 手机验证码登录
第三方登录：支持支付宝、钉钉、微博等快捷登录
企业用户：可使用 RAM 子账号进行权限隔离管理
⚠ 登录前请确保已完成阿里云账号的实名认证
3
开通百炼服务
首次进入百炼控制台时需要开通服务。新用户会获得免费的 Token 试用额度。
开通操作：点击「立即开通」→ 同意服务协议 → 确认开通
免费额度：新用户通常赠送一定量的免费 Token（具体以页面显示为准）
无需绑定支付方式即可开始试用免费额度
正式使用后需按量付费或购买资源包
4
创建 API Key
在百炼控制台中获取 API 调用的身份凭证。
路径：左侧菜单 → 「API 服务」→「API-Key 管理」→ 点击「创建 API-Key」
命名建议：按项目或用途区分，如 langchain-course、prod-chatbot
格式示例：sk-xxxxxxxxxxxxxxxxxxxxxxxx
重要：Key 创建后仅显示一次！请立即复制保存
✅
阿里云账号 vs 百炼的关系：你可以把阿里云理解为「操作系统」，百炼是其上的一个「AI 应用商店」。一个阿里云账号可以同时使用 ECS（服务器）、OSS（对象存储）、百炼（AI 模型）等多种云服务，统一账单管理。

3 百炼核心功能导览

百炼控制台提供了丰富的功能模块，以下是每个核心区域的简要说明：

📖
模型广场
浏览所有可用的大语言模型：查看各模型的参数规模、上下文长度、价格信息，支持在线体验对话效果后决定选用哪个模型
📡
应用中心
开箱即用的 AI 应用模板：对话助手、智能搜索、文本写作、文档分析等，可视化配置即可发布，无需编写代码
🔗
API 服务
获取 API Key、查看调用文档（含 DashScope SDK 和 OpenAI 兼容接口两种方式）、配置调用配额与限流策略
📋
数据集管理
上传和管理用于模型微调的训练数据、评估数据集，支持 JSONL/CSV/JSON 多种格式导入
📈
监控中心
实时查看 API 调用量、Token 消耗趋势、费用明细、错误率统计，支持设置用量告警阈值
🔬
模型微调
上传自有数据对 Qwen 等模型进行 SFT（监督微调），打造领域专属模型，支持全参数/LoRA 两种模式

4 百炼 API 调用方式

百炼提供了三种 API 调用方式，满足不同开发者的偏好和场景需求：

官方推荐
DashScope SDK
阿里云官方 Python SDK，类型提示完善，文档齐全，专为百炼平台设计
pip install dashscope
兼容模式
OpenAI 兼容接口
完全兼容 OpenAI API 格式，可直接用 openai 库调用，切换 base_url 即可
base_url = "https://dashscope.aliyuncs.com/compatible-mode/v1"
原生 REST
HTTP RESTful API
标准 HTTP 接口，适用于任何编程语言，最大灵活性但需手动处理细节
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation

DashScope SDK 调用示例

Python (DashScope SDK) 
# 安装：pip install dashscope
import dashscope

# 设置 API Key（也可通过环境变量 DASHSCOPE_API_KEY 设置）
dashscope.api_key = "在此填入你的百炼API Key"

from dashscope import Generation

# 调用通义千问模型
response = Generation.call(
    model="qwen-plus",           # 模型名称
    messages=[
        {"role": "system", "content": "你是一个有帮助的AI助手。"},
        {"role": "user",   "content": "介绍一下阿里云百炼平台。"},
    ],
    result_format='message',       # 返回消息格式
)

if response.status_code == 200:
    print("✅ 回复：", response.output.choices[0].message.content)
    print("📈 用量：", response.usage)
else:
    print("❌ 错误：", response.code, response.message)
💡
本课程推荐使用 OpenAI 兼容接口来调用百炼，原因如下：
• 与 DeepSeek 的调用代码保持一致，只需更换 base_url 和 api_key
• LangChain 的 ChatOpenAI 组件可以直接对接，无需额外适配
• 学习一次 OpenAI 格式，即可在所有兼容平台间自由切换
