1 什么是 LangChain？

LangChain 是一个开源的 LLM（大语言模型）应用开发框架，由 Harrison Chase 于 2022 年 10 月创建。它通过组件化、可组合的架构，让开发者能够高效构建端到端的 LLM 驱动应用。

💡
官方定义：LangChain 是一个用于开发由语言模型驱动的应用程序的框架。它使应用程序具备两大核心能力：
• 上下文感知（Context Awareness）：将语言模型连接到外部数据源
• 推理能力（Reasoning）：允许语言模型与其环境交互

简单来说，传统 LLM 应用像是「孤立的专家」——只能基于已有知识回答问题；而 LangChain 应用则是「连接的团队」——能够调用各种工具和资源来解决实际问题。你可以把它想象成一套智能积木系统，每个组件都是一块标准化的积木，可以自由拼接组合来构建复杂的 AI 应用。

为什么需要 LangChain？

直接调 API 的痛点LangChain 的解决方案
模型碎片化，各厂商 API 格式不统一统一抽象层：一套代码兼容 OpenAI / Anthropic / Ollama / DeepSeek 等
多轮对话需要手动管理上下文历史Memory 组件：自动管理会话记忆与上下文窗口
LLM 无法获取实时信息或私有数据RAG + Retrieval：检索增强生成，连接向量数据库与企业知识库
复杂任务需要硬编码流程逻辑Chains + Agents：声明式链式调用 + 自主决策的 Agent 循环
无法让 LLM 调用工具/执行操作Tools 集成：搜索引擎、数据库、API、文件系统等 100+ 工具
调试困难，难以追踪每一步执行过程LangSmith：可视化调试、测试评估、监控追踪平台
🌟
核心价值：LangChain 的价值不在于功能数量，而在于为 LLM 应用开发提供了一套系统化的框架——组件化拆解复杂应用为可复用模块，可组合灵活拼装不同组件构建工作流，可扩展随业务需求变化自由调整架构。

2 四层架构体系

LangChain 采用清晰的分层架构，各层职责明确且可独立使用。这是理解整个框架的关键：

应用层
langgraph
Agent 编排、状态管理、有状态工作流、人机协作
组件层
langchain
Chains、Agents、Retrieval 等通用认知架构策略
集成层
langchain-community
第三方模型、工具、向量库、文档加载器
核心层
langchain-core
基础抽象、Runnable 接口、LCEL、Message 类型

逐层详解

包名定位核心内容
langchain-core 框架基石 定义 Runnable 统一接口、LCEL 表达式语言、Base 抽象类（LLM/Embeddings/Retriever/Tool）、Message 类型体系、序列化协议。无任何第三方依赖，保持极致轻量。
langchain 认知架构 包含 Chains（链式调用）、Agents（智能体）、Retrieval Strategies（检索策略）等通用模式。不绑定任何特定集成，适用于所有模型提供商。
langchain-community 生态扩展 社区维护的第三方集成：20+ LLM（OpenAI/Anthropic/Gemini/Ollama）、100+ 工具、30+ 向量库（Pinecone/FAISS/Milvus）、50+ 文档加载器。所有依赖均为可选。
langgraph 图编排引擎 LangChain 的扩展包，通过有向图结构建模步骤（边和节点），实现有状态的多角色 LLM 应用。支持循环、分支、并行、持久化断点续跑、Human-in-the-Loop。
✅
关键结论：LangChain 是构建 AI 应用的「骨架」，LangGraph 是赋予其复杂行为的「肌肉」，LangSmith 则是提供洞察的「神经系统」。在 1.0 架构中，LangGraph 已成为 Agent 的默认运行时，实现了从「链」到「图」的底层升级。

3 核心模块一览

LangChain 将 LLM 应用开发拆分为六大核心模块，每个模块解决一类特定问题：

🤖
Models（模型）
统一接口调用各类 LLM（ChatOpenAI / ChatAnthropic / ChatOllama），支持同步/异步/流式/批量多种调用方式
📝
Prompts（提示词）
提示词模板（ChatPromptTemplate / StringPromptTemplate）、示例选择器、输出解析器（Output Parser）
🗃
Memory（记忆）
会话记忆管理，支持 BufferWindow / TokenWindow / ConversationSummary 等多种策略，解决多轮对话上下文问题
🔗
Chains（链）
用 LCEL 将多个组件串联成处理管道，支持顺序执行、分支、并行、动态路由等复杂逻辑
🔧
Tools（工具）
赋予 LLM 调用外部能力：搜索 API、数据库查询、代码执行、文件读写等 100+ 内置/自定义工具
🥓
Agents（智能体）
自主决策的 AI Agent，通过 ReAct 循环（Thought->Action->Observation）自主规划并执行多步任务
💡
额外模块（进阶）：除上述六大模块外，LangChain 还包含 Retrieval（检索）——文档加载、文本分割、向量化、检索匹配，是 RAG 系统的核心基础设施；以及 Callbacks（回调）——用于日志记录、追踪、流式事件监听等。

4 快速体验：第一个 Agent

让我们通过一个最简示例，感受 LangChain 的魅力。以下代码展示如何用不到 10 行核心逻辑创建一个具有搜索能力的 AI Agent：

Python 
# === 安装依赖 ===
# pip install langchain langchain-openai langchain-community

from langchain_openai import ChatOpenAI
from langchain.agents import create_react_agent, AgentExecutor
from langchain_community.tools import DuckDuckGoSearchRun

# 1. 初始化模型
llm = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0.7,
)

# 2. 准备工具（搜索能力）
tools = [DuckDuckGoSearchRun()]

# 3. 创建 ReAct Agent
agent = create_react_agent(llm, tools)
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,   # 打印思考过程
    handle_parsing_errors=True,  # 容错处理
)

# 4. 运行！
response = agent_executor.invoke({
    "input": "今天是几号？现在的天气怎么样？"
})

print(response["output"])
🚀
运行后你会看到类似这样的思考链路：
> Entering new AgentExecutor chain...
Thought: 我需要搜索今天的日期和天气信息...
Action: duckduckgo_search
Action Input: "today date weather Beijing"
Observation: [搜索结果...]
Thought: 根据搜索结果，我可以回答了...
Final Answer: 今天是xxx，北京天气xxx

这就是 Agent 的核心魅力——它不是简单地生成文字，而是能够自主思考、选择工具、获取信息、最终给出答案。整个过程对用户完全透明（verbose=True 时可看到完整推理链路）。

5 版本注意事项与常见坑点

在正式投入开发之前，有几个关键的版本和配置问题需要特别注意：

版本演进路线

版本时间节点主要变化
v0.0.x ~ v0.1.x2022.10 - 2023 初早期版本，Chain 子类为主（LLMChain / ConversationalRetrievalChain 等）
v0.2.x2024 初LCEL 成为首选方式，废弃旧 Chain 子类，推荐 Runnable 接口
v0.3.x2024 中架构重构：拆分为 core/community/main/graph 四包，引入 Pydantic v2
v1.02025稳定版发布，LangGraph 成 Agent 默认运行时，全面推荐 LCEL

新手必踩坑清单

⚠️
坑点 1 — 用错了导入路径：v0.3+ 后大量类被迁移到独立包中。例如 ChatOpenAI 不再从 langchain.chat_models 导入，而是从 langchain_openai 导入。安装时需 pip install langchain-openai。
⚠️
坑点 2 — API Key 泄露风险：绝对不要将 API Key 硬编码在源码中。应使用 .env 文件配合 python-dotenv 或系统环境变量加载。Git 提交前务必检查 .gitignore 是否排除了 .env 文件。
⚠️
坑点 3 — 依赖冲突：LangChain 生态涉及大量可选依赖。建议使用虚拟环境（venv / conda），按需安装：pip install langchain-openai langchain-community，避免一次性装全部依赖导致版本冲突。
⚠️
坑点 4 — 过时的教程代码：网上大量 2023 年的教程仍在使用 LLMChain、ConversationChain 等已废弃的 API。请以官方最新文档为准，优先使用 LCEL + Runnable 方式编写代码。
💪
推荐安装命令（精简版）：
pip install langchain langchain-core langchain-openai langchain-community python-dotenv
