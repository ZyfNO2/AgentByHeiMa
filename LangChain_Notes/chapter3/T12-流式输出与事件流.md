## 1. 为什么需要流式输出？

### 1.1 LLM 生成的本质

大语言模型（LLM）的文本生成过程是**逐 token（词元）**进行的：

```
非流式执行：
用户发送请求 ──────[等待 15 秒]──────→ 一次性返回完整回答
                    ⏳ 用户盯着空白屏幕...

流式执行：
用户发送请求 → t+0.1s "你" → t+0.2s "好" → t+0.3s "！" → ...
               👁️ 用户实时看到每个字的出现
```

### 1.2 流式输出的核心价值

| 维度 | 非流式 | 流式 |
|------|--------|------|
| **首字延迟 (TTFT)** | 等全部生成完才返回 | 第一个 token 即刻返回 |
| **用户体验** | 空白等待焦虑感强 | 打字机效果，感知延迟低 |
| **Agent 可观测性** | 只看到最终结果 | 实时看到思考过程和工具调用 |
| **长回答场景** | 可能等待数十秒 | 持续有反馈，可提前中断 |
| **资源占用** | 需缓存完整响应 | 可以边生成边传输，内存更省 |

### 1.3 Agent 场景中流式的特殊意义

在 Agent（智能体）系统中，流式输出的价值远超简单的"打字机效果"：

```
普通聊天流式:
  用户: "北京天气怎么样？"
  AI:   "根据查询结果，今天北京..."

Agent 流式（能看到"思考过程"）:
  用户: "帮我研究一下最新的 AI 论文"

  [🔵 思考中...] 用户想了解最新AI论文...
  [🔧 调用工具] search_web("latest AI papers 2025")
  [🔧 调用工具] query_arxiv("transformer architecture")
  [🟢 工具返回] 找到 23 条相关结果
  [🔵 思考中...] 综合分析搜索结果...
  [📝 生成回答] 根据最新研究发现...
```

这种**透明度**让用户能够：
- 了解 Agent 正在做什么（建立信任）
- 在 Agent 走偏时及时中断
- 对 Agent 的决策过程进行调试

## 2. stream() vs stream_events()

LangGraph 提供了两种流式 API，适用于不同场景：

### 2.1 stream() — 简单消息流

`stream()` 是最基础的流式接口，逐块（chunk）返回图的输出：

```python
from langgraph.graph import StateGraph, START, END

# 假设 app 是一个已编译的 StateGraph

# ====== 同步版本 ======
for chunk in app.stream({"messages": [user_message]}):
    # 每个 chunk 是一个节点执行后的 State 更新
    print(chunk)

# ====== 异步版本（推荐）=====
async for chunk in app.astream({"messages": [user_message]}):
    # chunk 格式: {"node_name": {state_update}}
    for node_name, state_update in chunk.items():
        if "messages" in state_update:
            msg = state_update["messages"][-1]
            print(msg.content, end="", flush=True)
```

**stream() 的特点**：

| 特性 | 说明 |
|------|------|
| **粒度** | 节点级别——每完成一个节点产生一次输出 |
| **内容** | State 的增量更新（delta） |
| **适用场景** | 简单的打字机效果、不需要细粒度控制 |
| **局限性** | 无法看到 LLM 内部的 token 流、无法区分事件类型 |

#### stream() 输出示例

```python
# 假设图结构: START → llm_node → tool_node → llm_node → END

async for chunk in app.astream({"input": "查询天气"}):
    print(chunk)
    # 输出序列:

# 第1个chunk: {'llm_node': {'messages': [AIMessage(content='我来帮你查询', ...)]}}
# 第2个chunk: {'tool_node': {'messages': [ToolMessage(content='北京: 晴 25°C', ...)]}}
# 第3个chunk: {'llm_node': {'messages': [AIMessage(content='北京今天晴朗，气温25°C', ...)]}}
```

### 2.2 stream_events() — 详细事件流（推荐）

`stream_events()` 是更强大的流式接口，提供**细粒度的事件类型**和**完整的执行追踪**：

```python
async for event in app.stream_events(
    {"messages": [user_message]},
    version="v2",      # 使用 v2 版本的事件格式
):
    event_type = event["event"]
    name = event.get("name", "")

    # 根据事件类型做不同的处理
    if event_type == "on_chat_model_stream":
        # LLM 正在输出 token
        token = event["data"]["chunk"].content
        print(token, end="", flush=True)

    elif event_type == "on_tool_start":
        # 工具开始调用
        print(f"\n\n>>> 调用工具: {name}")

    elif event_type == "on_tool_end":
        # 工具调用结束
        print(f"<<< 工具返回")

    elif event_type == "on_chain_start":
        # 图/链开始执行
        if name:  # 过滤掉顶层图的事件
            print(f"\n[{name}] 开始执行...")
```

**stream_events() vs stream() 对比**：

| 特性 | `stream()` | `stream_events()` |
|------|-----------|-------------------|
| **事件粒度** | 节点级别 | Token / 工具 / 链级别 |
| **事件类型** | 无（统一为 State 更新） | 丰富（10+ 种事件类型） |
| **LLM Token 流** | 不可见 | **可见**（逐 token） |
| **工具调用详情** | 只有最终结果 | 开始/结束/输入/输出 全部可见 |
| **嵌套组件可见** | 否 | **是**（可以看到子链/子图内部） |
| **性能开销** | 低 | 中等（需要更多 instrumentation） |
| **推荐场景** | 简单应用 | **生产环境 / 需要 UI 反馈** |

## 3. stream_events 事件类型详解

### 3.1 完整事件类型列表

| 事件类型 | 触发时机 | `event["data"]` 内容 | 典型用途 |
|----------|----------|---------------------|---------|
| **`on_chain_start`** | RunnableChain/StateGraph 开始执行 | `{"input": ...}` | 显示"正在处理..." |
| **`on_chain_end`** | RunnableChain/StateGraph 执行完毕 | `{"output": ...}` | 记录处理结果/耗时 |
| **`on_chat_model_start`** | LLM 开始调用 | `{"messages": [...]}` | 记录发给 LLM 的 prompt |
| **`on_chat_model_end`** | LLM 调用完成 | `{"message": AIMessage(...)}` | 获取完整回复 |
| **`on_chat_model_stream`** | LLM 输出**每个 token** | `{"chunk": AIMessageChunk(content="...")}` | **实现打字机效果** |
| **`on_tool_start`** | 工具开始执行 | `{"input": {...}, "name": "tool_name"}` | UI 显示"正在调用 xxx" |
| **`on_tool_end`** | 工具执行结束 | `{"output": ..., "name": "tool_name"}` | 显示工具返回值 |
| **`on_retries`** | 重试发生时 | 重试信息 | 错误处理/重试提示 |
| **`custom`** | 自定义事件（需手动触发） | 自定义数据 | 推送自定义状态给前端 |

### 3.2 事件对象结构详解

每个事件是一个字典，包含以下关键字段：

```python
{
    "event": "on_chat_model_stream",     # 事件类型字符串
    "name": "llm_node",                   # 触发该事件的 runnable 名称
    "run_id": UUID("..."),                # 本次运行的唯一 ID
    "tags": [],                           # 标签列表
    "metadata": {},                       # 元数据（可能包含 langgraph_step 等）
    "data": {                             # ★ 事件载荷（最重要）
        "chunk": AIMessageChunk(          # 对于 on_chat_model_stream
            content="Hello",              # 当前 token 的文本
            id=MessageId(...),
            response_metadata={...}
        )
    },
    "parent_ids": [UUID("...")],          # 父级 run_id 列表（用于追踪层级关系）
}
```

### 3.3 完整事件监听示例

```python
"""
完整的 stream_events 监听器
展示所有主要事件类型的处理方式
"""

import asyncio
from typing import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import create_react_agent
from langchain_core.messages import HumanMessage, SystemMessage


async def monitor_all_events(app, user_input: str):
    """全面监控 Agent 执行过程中的所有事件"""

    print("=" * 60)
    print(f"用户输入: {user_input}")
    print("=" * 60)

    # 统计变量
    stats = {
        "tokens": 0,
        "tool_calls": 0,
        "chain_entries": 0,
        "start_time": None,
    }

    async for event in app.stream_events(
        {"messages": [HumanMessage(content=user_input)]},
        version="v2",
    ):
        etype = event["event"]
        ename = event.get("name", "")
        data = event.get("data", {})

        # ========== 链/图级别 ==========
        if etype == "on_chain_start":
            stats["chain_entries"] += 1
            if ename and not ename.startswith("__root__"):
                print(f"\n{'─' * 40}")
                print(f"[▶ START] {ename}")
                if stats["chain_entries"] == 1:
                    import time
                    stats["start_time"] = time.perf_counter()
                # 显示输入摘要
                inp = data.get("input", {})
                if isinstance(inp, dict) and "messages" in inp:
                    msgs = inp["messages"]
                    if msgs:
                        last_msg = msgs[-1]
                        preview = getattr(last_msg, 'content', str(last_msg))[:80]
                        print(f"  输入: {preview}...")

        elif etype == "on_chain_end":
            if ename and not ename.startswith("__root__"):
                out = data.get("output", {})
                if isinstance(out, dict) and "messages" in out:
                    msgs = out["messages"]
                    if msgs:
                        last = msgs[-1]
                        content = getattr(last, 'content', '')
                        if content:
                            preview = content[:100] + ("..." if len(content) > 100 else "")
                            print(f"[◀ END] {ename} → {preview}")
                else:
                    print(f"[◀ END] {ename}")

        # ========== LLM 级别 ==========
        elif etype == "on_chat_model_start":
            print(f"  🤖 LLM 调用开始 ({ename})")
            msgs = data.get("messages", [])
            if msgs:
                total_chars = sum(len(getattr(m, 'content', '')) for m in msgs)
                print(f"     Prompt 总长度: {total_chars} 字符")

        elif etype == "on_chat_model_stream":
            # ★ 核心：逐 token 输出
            chunk = data.get("chunk")
            if chunk:
                token_content = chunk.content
                if token_content:
                    print(token_content, end="", flush=True)
                    stats["tokens"] += 1

        elif etype == "on_chat_model_end":
            message = data.get("message")
            if message:
                content_len = len(getattr(message, 'content', ''))
                print(f"\n  ✅ LLM 完成: {content_len} 字符, {stats['tokens']} tokens")

        # ========== 工具级别 ==========
        elif etype == "on_tool_start":
            stats["tool_calls"] += 1
            tool_name = ename or data.get("name", "unknown")
            tool_input = data.get("input", {})
            input_str = str(tool_input)[:100]
            print(f"\n  🔧 [{stats['tool_calls']}] 工具调用: {tool_name}")
            print(f"     参数: {input_str}")

        elif etype == "on_tool_end":
            tool_output = data.get("output", "")
            output_str = str(tool_output)[:150] + ("..." if len(str(tool_output)) > 150 else "")
            print(f"  🔨 工具返回: {output_str}")

        # ========== 自定义事件 ==========
        elif etype == "custom":
            print(f"  📡 自定义事件: {data}")

    # 最终统计
    if stats["start_time"]:
        elapsed = asyncio.get_event_loop().time() - stats["start_time"]
        print(f"\n{'=' * 60}")
        print(f"执行统计:")
        print(f"  总耗时: {elapsed:.2f}s")
        print(f"  Token 数: {stats['tokens']}")
        print(f"  工具调用: {stats['tool_calls']}")
        print(f"  链/图进入次数: {stats['chain_entries']}")
        print("=" * 60)


# 使用示例
# agent = create_react_agent(model, tools)
# await monitor_all_events(agent, "北京今天的天气怎么样？")
```

### 4.2 后端事件标准化函数

将原始 `stream_events` 转换为前端友好的标准格式：

```python
"""
事件标准化器：将 LangGraph 原始事件转换为前端友好格式
"""

from enum import Enum
from pydantic import BaseModel
from typing import Any, Optional, List
import json
import uuid


class AgentStatus(str, Enum):
    """Agent 状态枚举"""
    THINKING = "thinking"           # 正在思考
    TOOL_CALLING = "tool_calling"   # 正在调用工具
    TOOL_RESULT = "tool_result"     # 工具返回结果
    STREAMING = "streaming"         # 正在流式输出
    ERROR = "error"                 # 出错了
    DONE = "done"                   # 完成


class AgentEvent(BaseModel):
    """标准化后的 Agent 事件"""
    event_id: str                   # 唯一事件ID
    status: AgentStatus             # 当前状态
    timestamp: float                # 时间戳
    data: Optional[Any] = None      # 事件载荷
    metadata: dict = {}             # 元数据


def normalize_event(raw_event: dict) -> Optional[AgentEvent]:
    """
    将 LangGraph raw event 转换为标准化 AgentEvent
    """
    import time
    etype = raw_event.get("event", "")
    ename = raw_event.get("name", "")
    data = raw_event.get("data", {})

    now = time.time()

    # ---- 思考状态 ----
    if etype == "on_chain_start" and ename and "agent" in ename.lower():
        return AgentEvent(
            event_id=str(uuid.uuid4())[:8],
            status=AgentStatus.THINKING,
            timestamp=now,
            data={"node": ename, "message": f"{ename} 开始工作..."},
        )

    # ---- 工具调用 ----
    elif etype == "on_tool_start":
        return AgentEvent(
            event_id=str(uuid.uuid4())[:8],
            status=AgentStatus.TOOL_CALLING,
            timestamp=now,
            data={
                "tool_name": ename or data.get("name", "unknown"),
                "tool_input": data.get("input", {}),
            },
        )

    # ---- 工具返回 ----
    elif etype == "on_tool_end":
        return AgentEvent(
            event_id=str(uuid.uuid4())[:8],
            status=AgentStatus.TOOL_RESULT,
            timestamp=now,
            data={
                "tool_name": ename or data.get("name", "unknown"),
                "tool_output": data.get("output"),
            },
        )

    # ---- Token 流 ----
    elif etype == "on_chat_model_stream":
        chunk = data.get("chunk")
        if chunk and chunk.content:
            return AgentEvent(
                event_id=str(uuid.uuid4())[:8],
                status=AgentStatus.STREAMING,
                timestamp=now,
                data={
                    "token": chunk.content,
                    "is_complete": False,
                },
            )

    # ---- 完成 ----
    elif etype == "on_chain_end" and ename and "__root__" in ename:
        output = data.get("output", {})
        messages = output.get("messages", []) if isinstance(output, dict) else []
        final_content = ""
        if messages:
            last = messages[-1]
            final_content = getattr(last, 'content', '')

        return AgentEvent(
            event_id=str(uuid.uuid4())[:8],
            status=AgentStatus.DONE,
            timestamp=now,
            data={
                "full_content": final_content,
                "message_count": len(messages),
            },
        )

    # 不关心的事件类型返回 None
    return None


async def event_stream_generator(app, user_message: str):
    """
    异步生成器：将 stream_events 转换为 SSE 友好的事件流
    供 FastAPI 等 Web 框架直接使用
    """
    async for raw_event in app.stream_events(
        {"messages": [HumanMessage(content=user_message)]},
        version="v2",
    ):
        normalized = normalize_event(raw_event)
        if normalized:
            # SSE 格式: data: <json>\n\n
            yield f"data: {normalized.model_dump_json()}\n\n"

    # 发送结束标记
    end_event = AgentEvent(
        event_id="end",
        status=AgentStatus.DONE,
        timestamp=time.time(),
        data={"signal": "STREAM_COMPLETE"},
    )
    yield f"data: {end_event.model_dump_json()}\n\n"
```

## 5. SSE / WebSocket 集成

### 5.1 Server-Sent Events (SSE) 方案

SSE 是实现服务端推送的最简单方案，**单向通信**（服务器→浏览器），适合 Agent 响应场景：

#### 后端：FastAPI + SSE

```python
"""
FastAPI SSE 集成示例
将 LangGraph Agent 的流式输出通过 SSE 推送到前端
"""

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from typing import Optional
import json
import uvicorn

app_fastapi = FastAPI(title="Agent Streaming API")


class ChatRequest(BaseModel):
    message: str
    session_id: Optional[str] = None


@app_fastapi.post("/chat/stream")
async def chat_stream(request: ChatRequest):
    """
    SSE 流式聊天端点
    返回 text/event-stream 类型的响应
    """

    async def generate():
        # 导入你的 Agent 应用
        from my_agent import agent_app

        try:
            async for event in agent_app.stream_events(
                {"messages": [HumanMessage(content=request.message)]},
                version="v2",
            ):
                # 转换为标准化事件
                normalized = normalize_event(event)
                if normalized:
                    yield f"data: {normalized.model_dump_json()}\n\n"

        except Exception as e:
            error_event = {
                "status": "error",
                "data": {"message": str(e)},
                "timestamp": time.time(),
            }
            yield f"data: {json.dumps(error_event)}\n\n"

        # 结束信号
        yield f"data: {json.dumps({'status': 'done', 'signal': 'END'})}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        generate(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
            "X-Accel-Buffering": "no",  # 禁用 nginx 缓冲
        },
    )


if __name__ == "__main__":
    uvicorn.run(app_fastapi, host="0.0.0.0", port=8000)
```

```html
        // ========== 核心函数 ==========
        function sendMessage() {
            const input = document.getElementById('user-input');
            const message = input.value.trim();
            if (!message) return;

            // 显示用户消息
            appendUserMessage(message);
            input.value = '';
            document.getElementById('send-btn').disabled = true;

            // 创建 Agent 消息区域
            currentAgentDiv = appendAgentMessageContainer();

            // 建立 SSE 连接
            const evtSource = new EventSource(
                `/chat/stream?message=${encodeURIComponent(message)}`
            );

            let fullContent = '';

            evtSource.onmessage = function(event) {
                const data = JSON.parse(event.data);

                // 结束信号
                if (data.signal === 'END' || data === '[DONE]') {
                    evtSource.close();
                    finalizeAgentMessage();
                    document.getElementById('send-btn').disabled = false;
                    return;
                }

                handleAgentEvent(data);
            };

            evtSource.onerror = function() {
                console.error('SSE 连接错误');
                appendStatus('连接断开', 'error');
                evtSource.close();
                document.getElementById('send-btn').disabled = false;
            };
        }

        // ========== 事件处理器 ==========
        function handleAgentEvent(event) {
            switch (event.status) {
                case 'thinking':
                    appendStatus(`💭 ${event.data.node || '思考中'}...`, 'thinking');
                    break;

                case 'tool_calling':
                    const toolBox = document.createElement('div');
                    toolBox.className = 'tool-call-box';
                    toolBox.innerHTML =
                        `<strong>🔧 ${event.data.tool_name}</strong><br>` +
                        `<code>${JSON.stringify(event.data.tool_input).slice(0, 200)}</code>`;
                    currentAgentDiv.querySelector('.agent-content').appendChild(toolBox);
                    appendStatus(`调用工具: ${event.data.tool_name}`, 'tool');
                    break;

                case 'tool_result':
                    const resultBox = document.createElement('div');
                    resultBox.className = 'tool-call-box';
                    resultBox.style.borderLeft = '3px solid #28a745';
                    resultBox.innerHTML =
                        `<strong>✅ ${event.data.tool_name} 返回</strong><br>` +
                        `${String(event.data.tool_output).slice(0, 300)}`;
                    currentAgentDiv.querySelector('.agent-content').appendChild(resultBox);
                    break;

                case 'streaming':
                    // 追加 token 到内容区
                    fullContent += event.data.token;
                    updateStreamingContent(fullContent);
                    appendStatus('正在输入...', 'streaming');
                    break;

                case 'error':
                    appendStatus(`❌ 错误: ${event.data.message}`, 'error');
                    break;

                case 'done':
                    finalizeAgentMessage(event.data.full_content || fullContent);
                    break;
            }
        }

        // ========== DOM 操作辅助函数 ==========
        function appendUserMessage(text) {
            const div = document.createElement('div');
            div.className = 'message user-message';
            div.textContent = text;
            document.getElementById('chat-container').appendChild(div);
        }

        function appendAgentMessageContainer() {
            const div = document.createElement('div');
            div.className = 'message agent-message';
            div.innerHTML = `
                <div class="agent-status"></div>
                <div class="agent-content"></div>
            `;
            document.getElementById('chat-container').appendChild(div);
            scrollToBottom();
            return div;
        }

        function appendStatus(text, type) {
            if (!currentAgentDiv) return;
            const statusDiv = currentAgentDiv.querySelector('.agent-status');
            const badge = document.createElement('span');
            badge.className = `status-badge status-${type}`;
            badge.textContent = text;
            statusDiv.innerHTML = '';  // 清除旧状态
            statusDiv.appendChild(badge);
        }

        function updateStreamingContent(text) {
            if (!currentAgentDiv) return;
            const contentDiv = currentAgentDiv.querySelector('.agent-content');
            // 找到或创建文本节点
            let textNode = contentDiv.querySelector('.streaming-text');
            if (!textNode) {
                textNode = document.createElement('div');
                textNode.className = 'streaming-text';
                textNode.style.whiteSpace = 'pre-wrap';
                contentDiv.appendChild(textNode);
            }
            textNode.textContent = text;
            scrollToBottom();
        }

        function finalizeAgentMessage(finalText) {
            if (!currentAgentDiv) return;
            const contentDiv = currentAgentDiv.querySelector('.agent-content');
            let textNode = contentDiv.querySelector('.streaming-text');
            if (textNode && finalText) {
                textNode.textContent = finalText;
            }
            appendStatus('✅ 完成', 'done');
            scrollToBottom();
        }

        function scrollToBottom() {
            const container = document.getElementById('chat-container');
            container.scrollTop = container.scrollHeight;
        }
    </script>
</body>
</html>
```

### 5.2 WebSocket 方案（双向通信）

如果需要**客户端也能主动发送消息**（如中途打断 Agent），则需要 WebSocket：

```python
"""
FastAPI + WebSocket 双向流式通信
支持客户端随时发送 stop/cancel 信号
"""

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
import json
import asyncio

app_ws = FastAPI()


@app_ws.websocket("/ws/chat")
async def websocket_chat(websocket: WebSocket):
    await websocket.accept()

    # 用于接收取消信号的标志
    cancelled = asyncio.Event()

    async def receive_messages():
        """持续监听客户端消息"""
        while True:
            try:
                data = await websocket.receive_text()
                msg = json.loads(data)
                if msg.get("type") == "cancel":
                    cancelled.set()
                    await websocket.send_text(json.dumps({
                        "type": "cancelled",
                        "message": "已取消当前操作"
                    }))
            except WebSocketDisconnect:
                break

    async def send_agent_stream(user_message):
        """向客户端推送 Agent 事件流"""
        try:
            async for event in agent_app.stream_events(
                {"messages": [HumanMessage(content=user_message)]},
                version="v2",
                config={"callbacks": [CancelCallback(cancelled)]},  # 支持取消
            ):
                if cancelled.is_set():
                    break

                normalized = normalize_event(event)
                if normalized:
                    await websocket.send_text(normalized.model_dump_json())

            await websocket.send_text(json.dumps({
                "status": "done", "signal": "END"
            }))
        except Exception as e:
            await websocket.send_text(json.dumps({
                "status": "error", "message": str(e)
            }))

    # 启动收发两个协程
    receive_task = asyncio.create_task(receive_messages())

    # 等待第一条消息作为初始输入
    initial_data = await websocket.receive_text()
    initial_msg = json.loads(initial_data)

    send_task = asyncio.create_task(
        send_agent_stream(initial_msg.get("message", ""))
    )

    # 等待任一任务完成
    done, pending = await asyncio.wait(
        [receive_task, send_task],
        return_when=asyncio.FIRST_COMPLETED
    )

    # 清理
    for task in pending:
        task.cancel()

    await websocket.close()
```

### 5.3 SSE vs WebSocket 选择指南

| 特性 | SSE | WebSocket |
|------|-----|-----------|
| **通信方向** | 单向（服务端→客户端） | **双向** |
| **协议** | HTTP（简单） | 独立协议（需升级） |
| **自动重连** | 浏览器原生支持 | 需自行实现 |
| **代理/CDN 友好** | **是** | 通常不支持 |
| **取消/打断** | 需额外机制 | **原生支持** |
| **复杂度** | 低 | 中等 |
| **适用场景** | Agent 回复流式展示 | 需要交互控制的复杂 Agent |

**建议**：大多数 Agent 聊天场景使用 **SSE** 已足够；只有需要客户端主动干预（暂停、修改方向、上传文件等）时才上 WebSocket。

## 6. Token 优化技巧

### 6.1 流式输出的 Token 统计

在流式过程中实时统计 Token 用量：

```python
class TokenTracker:
    """Token 使用量跟踪器"""

    def __init__(self):
        self.prompt_tokens = 0
        self.completion_tokens = 0
        self.total_tokens = 0
        self.start_time = None
        self.first_token_time = None

    def on_llm_start(self, event):
        """LLM 开始调用"""
        import time
        self.start_time = time.perf_counter()
        # 估算 prompt tokens（简化）
        messages = event["data"].get("messages", [])
        self.prompt_tokens = sum(
            len(getattr(m, 'content', '')) // 4  # 粗略估算: ~4字符/token
            for m in messages
        )

    def on_token(self, event):
        """收到一个 token"""
        import time
        if self.first_token_time is None:
            self.first_token_time = time.perf_counter()
        self.completion_tokens += 1

    def get_stats(self):
        """获取统计信息"""
        import time
        now = time.perf_counter()
        self.total_tokens = self.prompt_tokens + self.completion_tokens

        ttft = None
        if self.start_time and self.first_token_time:
            ttft = (self.first_token_time - self.start_time) * 1000  # ms

        throughput = None
        if self.first_token_time:
            elapsed = now - self.first_token_time
            throughput = self.completion_tokens / elapsed if elapsed > 0 else 0

        return {
            "prompt_tokens": self.prompt_tokens,
            "completion_tokens": self.completion_tokens,
            "total_tokens": self.total_tokens,
            "ttft_ms": round(ttft, 1) if ttft else None,
            "tokens_per_second": round(throughput, 1) if throughput else None,
        }


# 使用
tracker = TokenTracker()

async for event in app.stream_events(input_data, version="v2"):
    if event["event"] == "on_chat_model_start":
        tracker.on_llm_start(event)
    elif event["event"] == "on_chat_model_stream":
        tracker.on_token(event)
        # 可选：每 N 个 token 打印一次统计
        if tracker.completion_tokens % 20 == 0:
            print(f"  [Stats] {tracker.get_stats()}")

print(f"\n最终统计: {tracker.get_stats()}")
```

### 6.2 TTFT（Time To First Token）优化

TTFT 是影响用户体验的关键指标——从发送请求到收到第一个 token 的时间：

```
TTFT 组成：
┌──────────────────────────────────────────────────────┐
│  请求排队 → Prompt 处理 → 首个 Token 生成 → 网络传输  │
│   t_queue    t_prompt       t_generate       t_net    │
└──────────────────────────────────────────────────────┘
```

**优化策略**：

| 环节 | 优化方法 | 预期收益 |
|------|---------|---------|
| **Prompt 处理** | 缩短 System Prompt、减少 few-shot 示例数量 | 减少 10~50% 的 prompt 处理时间 |
| **模型选择** | 使用更小的模型做初步响应，大模型做精修 | 小模型 TTFT 可缩短 60%+ |
| **连接池** | 复用 LLM API 连接（HTTP keep-alive） | 减少握手开销 |
| **KV Cache** | 对话历史使用 KV Cache 避免重复计算 | 多轮对话显著加速 |
| **预填充** | 对高频前缀（如 System Prompt）做预计算 | 减少 prompt 处理时间 |
| **推测解码** | 小模型预测 token，大模型并行验证 | 提高吞吐但不一定改善 TTFT |

### 6.3 取消机制（Abort Signal）

允许用户或系统在流式过程中**主动中止**：

```python
"""
带取消机制的流式执行
"""

import asyncio


class AbortController:
    """类似浏览器 AbortController 的取消控制器"""

    def __init__(self):
        self._abort_event = asyncio.Event()
        self._reason = None

    @property
    def signal(self):
        return self._abort_event

    @property
    def aborted(self):
        return self._abort_event.is_set()

    def abort(self, reason: str = "用户取消"):
        """触发取消"""
        self._reason = reason
        self._abort_event.set()

    @property
    def abort_reason(self):
        return self._reason


async def cancellable_stream(app, input_data, controller: AbortController):
    """支持取消的流式执行"""

    async for event in app.stream_events(input_data, version="v2"):
        # 每次迭代检查是否被取消
        if controller.aborted:
            print(f"[!] 流式输出已中止: {controller.abort_reason}")
            # 返回一个取消事件后退出
            yield {
                "status": "cancelled",
                "reason": controller.abort_reason,
                "partial_results": "...已生成的部分内容...",
            }
            return

        yield normalize_event(event)

    if not controller.aborted:
        yield {"status": "complete"}


# ====== 使用示例 ======

async def demo_cancellation():
    app = build_my_agent()
    controller = AbortController()

    # 模拟一个异步任务：3秒后自动取消
    async def auto_cancel_after_3s():
        await asyncio.sleep(3)
        controller.abort(reason="超时自动取消")

    cancel_task = asyncio.create_task(auto_cancel_after_3s())

    # 开始流式执行
    async for event in cancellable_stream(
        app,
        {"messages": [HumanMessage(content="写一篇长文章")]},
        controller,
    ):
        print(event)

    cancel_task.cancel()
```

## 本章小结

本章全面介绍了 LangGraph 中的**流式输出与事件流**技术体系：

1. **两种流式 API**：`stream()` 提供节点级别的 State 增量更新流，适合简单场景；**`stream_events()`（推荐）** 提供 Token 级别、工具级别、链级别的丰富事件类型，是生产环境构建实时 UI 的基础。

2. **事件类型体系**涵盖 9 种核心事件：链/图的起止、LLM 的 start/stream/end、工具的 start/end、重试通知以及自定义事件。通过事件对象的 `event`、`name`、`data` 字段可以获取完整的执行上下文。

3. **前后端集成**展示了从事件标准化（Pydantic Model）、**SSE 推送**（FastAPI + `StreamingResponse`）、到前端渲染（JavaScript `EventSource` + DOM 操作）的完整链路。同时对比了 SSE 与 WebSocket 的选择依据。

4. **性能优化**方面包括：Token 实时统计与 `TokenTracker`、TTFT 优化策略（模型选择、Prompt 优化、KV Cache）、基于 `AbortController` 的取消机制、以及 Nginx/Gunicorn 层面的缓冲配置。

流式输出是 Agent 系统**用户体验的核心差异化因素**——它不仅实现了打字机效果，更重要的是提供了 Agent 决策过程的**可观测性和可控性**。
