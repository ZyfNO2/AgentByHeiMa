1 项目概述：AI 私厨是什么？

AI 私厨（AI Personal Chef）是一个基于 LangChain + 多模态大模型 的智能食谱推荐应用。用户只需拍摄冰箱或厨房中的食材照片，或用自然语言描述手中的食材与口味偏好，AI 就能自动识别食材、搜索匹配菜谱，并按营养价值和制作难度进行智能排序推荐。

💡

核心价值主张

解决"打开冰箱不知道做什么吃"的日常痛点。通过多模态输入（图片+文本）+ Web 搜索工具 + Agent 决策循环，实现从「有什么食材」到「今晚吃什么」的全链路智能化。

2 功能清单梳理

经过需求分析，我们将 AI 私厨拆解为以下核心功能模块：

📷

多模态输入

支持图片上传识别食材 + 自然语言描述口味偏好

🔎

智能菜谱搜索

根据食材自动检索匹配菜谱并排序推荐

🤝

交互式调整

根据用户反馈动态调整推荐结果

🍽

营养信息查询

提供每道菜的卡路里、营养成分分析

3 技术选型确认

基于项目需求和课程所学知识，确定以下技术栈：

技术层 选择方案 选型理由
Agent 框架 LangChain + LangGraph Agent 编排 + 状态管理，支持 ReAct 循环
多模态模型 qwen-vl-max / qwen3.5-plus 阿里百炼通义千问，支持图片+文本联合理解
Web 搜索 Tavily Search API 专为 AI Agent 设计的结构化搜索结果
记忆存储 SQLite (SqliteSaver) 轻量级持久化会话记忆，无需额外数据库服务
后端框架 FastAPI 高性能异步框架，原生支持流式输出 SSE
对象存储 阿里云 OSS 存储用户上传的食材图片和菜谱配图

4 最小可行产品（MVP）验证

在正式开发完整系统之前，我们先用 Jupyter Notebook 验证核心链路是否跑通。这是敏捷开发中「先验证再扩展」的关键步骤。

  1. 环境变量配置

    配置 DASHSCOPE_API_KEY 和 TAVILY_API_KEY，确保模型和搜索工具可用。

  2. 定义搜索工具

    使用 TavilySearch 封装 web_search 工具，设置 max_results=5。

  3. 初始化多模态模型

    通过 init_chat_model 加载 qwen3.5-plus，设置 base_url 为百炼兼容模式。

  4. 创建 Agent 并测试

    组合 Model + Tool + Memory，传入一张冰箱照片测试端到端流程。

Python — MVP PoC 核心代码 
# === MVP 验证：最小可行产品 PoC ===
from dotenv import load_dotenv
from langchain_tavily import TavilySearch
from langchain.chat_models import init_chat_model
import os

# 1. 加载环境变量
load_dotenv()

# 2. 定义 Web 搜索工具
web_search = TavilySearch(
    max_results=5,
    topic="general",
)

# 3. 初始化多模态模型（支持图片输入）
model = init_chat_model(
    model="qwen3.5-plus",
    model_provider="openai",
    base_url=os.getenv("DASHSCOPE_BASE_URL"),
    api_key=os.getenv("DASHSCOPE_API_KEY")
)

# 4. 创建 Agent（Model + Tools 组合）
agent = create_agent(
    model=model,
    tools=[web_search],
    system_prompt="""你是一名私人厨师。
收到用户提供的食材照片后：
1. 识别所有可见食材，评估新鲜度
2. 调用 web_search 搜索可行菜谱
3. 按营养价值和难度排序推荐
4. 输出结构化建议报告"""
)

# 5. 测试：传入图片 + 文本消息
result = agent.invoke({
    "messages": [
        {"type": "image_url", "image_url": {"url": "fridge.jpg"}},
        {"role": "user", "content": "根据这些食材给我推荐一道菜"}
    ]
})
print(result["messages"][-1].content)
✅

PoC 验证通过标准

当 Agent 能够：(1) 正确识别图片中的食材名称；(2) 自动调用 Tavily 搜索到相关菜谱；(3) 返回结构化的推荐报告 —— 则说明核心技术链路已打通，可以进入正式工程化阶段。
