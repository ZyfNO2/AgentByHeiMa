Ollama 本地部署

掌握 Ollama 本地大模型运行工具的安装、配置与使用，了解模型下载管理、API 服务启动，以及与 LangChain 的无缝集成方案。让 AI 模型在你的电脑上自由奔跑。

1 Ollama 是什么？

Ollama 是一款开源的本地大模型运行工具，旨在让每个人都能在自己的电脑上轻松运行 LLM（大型语言模型）。它的核心理念是：一键安装、命令行友好、开箱即用。

为什么选择 Ollama？相比手动配置 llama.cpp、GGUF 转换、CUDA 环境，Ollama 将所有复杂性封装在一条命令中。ollama pull <model> 即可完成从下载到部署的全流程。同时它内置了 API 服务，天然兼容 OpenAI 格式，可直接接入 LangChain。

平台支持

Ollama 全平台覆盖，无论你使用什么操作系统都能流畅运行：

平台支持状态推荐场景
macOS (Apple Silicon)原生支持 (Metal)M1/M2/M3/M4 Mac 首选，性能优异
Linux原生支持 (CUDA/ROCm)服务器部署、NVIDIA GPU 加速
WindowsWSL2 原生支持Windows 10/11 用户通过 WSL2 运行
Docker官方镜像可用容器化部署、CI/CD 集成

2 安装与配置

Ollama 的安装过程极其简单，官网提供一键安装包，无需复杂的环境配置：

Bash / Terminal 
# ========== Step 1: 下载安装 ==========
# 访问 https://ollama.com/download 选择你的平台
# macOS: 下载 .dmg 文件拖入 Applications
# Linux: 执行一键安装脚本
# Windows: 下载 .exe 安装包（或使用 winget）

# ========== Step 2: 验证安装 ==========
# 打开终端（Terminal / PowerShell），执行：
ollama --version
# 输出示例: ollama version is 0.5.7


# ========== Step 3: 下载模型 ==========
# 格式: ollama pull <模型名>:<版本>
ollama pull qwen2.5:7b       # 通义千问 2.5 版 7B 参数
ollama pull llama3.2         # Meta Llama 3.2 最新版
ollama pull deepseek-r1:7b   # DeepSeek R1 推理模型


# ========== Step 4: 启动对话 ==========
# 格式: ollama run <模型名>
ollama run qwen2.5:7b

# 进入交互式对话界面后，直接输入文字即可与模型对话
# 输入 /bye 退出对话
🌟
首次使用建议：新手推荐先从 qwen2.5:7b 或 llama3.2:latest 开始——它们体积适中（约 4~5GB）、中文能力优秀、对显存要求不高（8GB 显存即可流畅运行）。等熟悉操作后再尝试更大的模型。

3 常用命令速查表

Ollama 的 CLI 设计简洁直观，以下是日常开发中最常用的命令一览：

命令功能说明示例
ollama list 查看已下载的所有模型列表 ollama list
ollama pull <model> 从仓库下载指定模型到本地 ollama pull qwen2.5:7b
ollama rm <model> 删除已下载的模型（释放磁盘空间） ollama rm llama3.2
ollama ps 查看当前正在运行的模型进程 ollama ps
ollama run <model> 启动交互式对话模式 ollama run deepseek-r1
ollama serve 启动 API 服务器（默认端口 11434） ollama serve
ollama show <model> 查看模型的详细信息（参数量、大小等） ollama show qwen2.5:7b
ollama create 基于已有模型创建自定义 Modelfile ollama create mymodel -f Modelfile
📋
实用技巧：ollama run 支持管道输入！你可以用 echo "翻译成英文" | ollama run qwen2.5:7b 实现非交互式单次调用，非常适合脚本集成和自动化场景。

4 Ollama API 服务

Ollama 不仅是一个命令行工具，它还内置了一个兼容 OpenAI 格式的 RESTful API 服务器。这意味着你可以用调用 OpenAI API 的方式来调用本地运行的 Ollama 模型。

服务信息

项目值
默认地址http://localhost:11434
聊天接口POST /api/chat 或 POST /v1/chat/completions
认证方式默认无需认证（本地安全）
协议格式OpenAI 兼容格式 + Ollama 原生格式
流式支持SSE (Server-Sent Events)，stream: true

LangChain 集成代码

Python - LangChain + Ollama 
# === 安装依赖 ===
# pip install langchain-ollama

from langchain_ollama import ChatOllama

# === 创建 Ollama LLM 实例 ===
llm = ChatOllama(
    model="qwen2.5:7b",              # 已通过 ollama pull 下载的模型名
    base_url="http://localhost:11434", // Ollama 默认端口
    temperature=0.7,                   // 温度参数
)

# === 同步调用 ===
response = llm.invoke("用三句话介绍一下量子计算")
print(response.content)


# === 流式调用 ===
for chunk in llm.stream("写一首关于春天的短诗"):
    print(chunk.content, end="", flush=True)
💡
关键优势：因为 Ollama 兼容 OpenAI API 格式，你也可以直接用 langchain-openai 包的 ChatOpenAI 类来连接 Ollama——只需将 base_url 设为 "http://localhost:11434/v1" 即可。两种方式效果一致。

5 模型选择指南

选择合适的模型需要在模型能力和硬件资源之间做权衡。以下对照表帮助你根据自身设备条件做出最优选择：

参数量 vs 显存需求

7B 参数 (如 Qwen2.5-7B)~8 GB VRAM
7B
13B-14B 参数 (如 Qwen2.5-14B)~16 GB VRAM
14B
32B-34B 参数 (如 Command-R)~32 GB VRAM
32B
70B+ 参数 (如 Llama 3.1-70B)~48+ GB VRAM
70B+

量化版本说明

量化等级体积压缩质量损失推荐场景
Q4_K_M约 4-bit轻微日常首选，平衡速度与质量
Q5_K_M约 5-bit很小对质量有更高要求时选用
Q6_K约 6-bit极小需要接近原版精度时
Q8_0约 8-bit几乎无感知追求极致质量、显存充足
fp16 (无量化)原始精度无研究/评测用途，资源充裕

推荐组合

✅
日常通用：Qwen2.5-7B-Instruct-Q4_K_M — 中文能力强、速度快、8GB 显存即可

深度推理：DeepSeek-R1-Distill-7B — 推理任务表现惊艳，自带思维链

代码生成：Llama 3.2-3B 或 Qwen2.5-Coder-7B — 轻量高效、代码专项优化

长文本处理：Qwen2.5-32B 或 Command-R-35B — 支持 128K 上下文窗口

6 优缺点分析

在使用 Ollama 进行本地模型部署之前，全面了解其优劣势有助于做出合理的技术选型决策：

✓ 优势 Advantages

  • 完全免费 —— 无 API 调用费用，一次下载无限使用
  • 隐私安全 —— 数据不出本机，适合敏感数据场景
  • 无网络依赖 —— 离线环境也能正常运行
  • 低延迟 —— 本地推理，无网络传输开销
  • 易于集成 —— OpenAI 兼容 API，LangChain 一行代码接入
  • 生态丰富 —— 支持数百种开源模型，持续更新

✗ 劣势 Limitations

  • 受限于硬件 —— 大模型需要大量显存/内存（70B 需 48GB+）
  • 小模型能力弱 —— 7B 模型在复杂推理上远不如 GPT-4/Claude
  • 多用户困难 —— 单机难以支撑高并发请求
  • 更新维护 —— 需要手动管理模型版本和依赖
  • 缺少企业特性 —— 无内置限流、日志、监控等功能
⚠️
选型建议：如果你是个人开发者或小团队，需要处理敏感数据、控制成本、或者离线工作环境 —— Ollama 是绝佳选择。如果需要面向大规模生产环境、要求顶级模型能力，则应考虑云端 API（OpenAI / DeepSeek / Anthropic）或自建 vLLM 推理集群。
