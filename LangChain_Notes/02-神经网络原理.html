第 02 集 · 1.2 神经网络原理

神经网络原理

从生物神经元到人工感知机，理解神经网络的基本计算单元；掌握激活函数的选择策略与多层网络的层次化表征能力；深入反向传播算法的核心思想，以及防止过拟合的正则化技术。这是通往大语言模型的必经之路。

时长 16:15 第1章 基础理论 理论基础

1 生物神经元 vs 人工神经元

人工神经网络的设计灵感直接来源于生物大脑中的神经系统。理解这种类比关系，是掌握神经网络原理的第一步：

🧠
生物神经元
Biological Neuron
  • 树突 Dendrite 接收来自其他神经元的电信号输入
  • 胞体 Soma 整合所有输入信号，进行累积处理
  • 轴突 Axon 将处理后的信号传递给下游神经元
  • 突触 Synapse 神经元之间的连接点，信号强度可调节
➔
🤖
人工神经元
Artificial Neuron / Perceptron
  • 输入 x 接收外部数据或上一层神经元的输出
  • 权重 w 每个输入的重要性系数（可学习参数）
  • 偏置 b 类似于线性方程的截距，增加灵活性
  • 激活 f() 非线性变换函数，决定是否「 firing 」
💡
核心映射关系：树突 → 输入（Input）、突触强度 → 权重（Weight）、胞体整合 → 加权求和、阈值触发 → 激活函数（Activation Function）、轴突输出 → 神经元输出（Output）。人工神经元是对生物神经元的高度简化数学模型。

2 感知机（Perceptron）原理

感知机是由 Frank Rosenblatt 于 1957 年提出的最基础的神经网络单元。它的计算过程可以精确地用数学公式描述——这也是所有深度学习模型的基石：

感知机核心公式
y = f( Σi wi · xi + b )
xi — 第 i 个输入特征值（如像素值、词向量维度） wi — 对应第 i 个输入的权重（Weight），表示该输入的重要程度 b — 偏置项（Bias），使决策边界不必经过原点 Σw·x + b — 加权求和 + 偏置，即线性组合结果 f(·) — 激活函数（Activation Function），引入非线性能力 y — 神经元的最终输出

感知机的三步计算流程

1
加权求和
将每个输入乘以其权重后累加
z = w·x + b
2
激活函数
对线性结果做非线性变换
y = f(z)
3
输出
产生神经元的输出信号
传给下一层或作为最终结果
✅
为什么需要激活函数？如果没有激活函数（即 f(z) = z），无论网络有多少层，最终的输出都只是输入的线性组合——多层就等价于一层。激活函数引入了非线性，使得神经网络能够逼近任意复杂的函数，这是深度学习的核心力量来源。

3 常用激活函数对比

激活函数的选择直接影响模型的训练效果和收敛速度。以下是五种最常用的激活函数及其特性对比：

函数名 数学表达式 取值范围 优点 缺点 / 适用场景
Sigmoid σ(x) = 1/(1+e^(-x)) (0, 1) 输出有界、可解释为概率、平滑可导 梯度消失严重；输出非零中心化。适用于二分类输出层。
现代已少用于隐藏层
Tanh tanh(x) = (e^x-e^(-x))/(e^x+e^(-x)) (-1, 1) 零中心化输出、比 Sigmoid 收敛更快 仍有梯度消失问题。在 RNN/LSTM 中仍有使用，但隐藏层也已被替代。
ReLU ReLU(x) = max(0, x) [0, +∞) 计算极快、缓解梯度消失、稀疏激活 当前默认首选。「Dying ReLU」问题：负区间梯度为 0 导致神经元死亡。可用 Leaky ReLU 缓解。
GELU x*Φ(x) (Φ 为高斯 CDF) (≈-0.17, +∞) 平滑、性能优于 ReLU、理论更优雅 LLM 标准选择。GPT-3 / BERT / LLaMA 全部使用 GELU 作为激活函数。
Swish / SiLU x * sigmoid(x) (≈-0.28, +∞) 无界平滑、负区保留梯度、自门控 计算量略高于 ReLU。在部分 LLM 变体中使用，表现接近 GELU。
💡
选型速查指南：
• 隐藏层（一般场景） → ReLU（简单高效）或 GELU（LLM 场景）
• 二分类输出层 → Sigmoid
• 多分类输出层 → SoftMax
• RNN / LSTM → Tanh 或 Sigmoid

4 多层前馈神经网络（MLP）

单个感知机的能力非常有限（只能解决线性可分问题）。将多个神经元按层级组织起来，就构成了多层感知机（Multi-Layer Perceptron，简称 MLP），也叫全连接前馈神经网络：

为什么需要「深层」？— 特征层次化抽象

深层网络的每一层都在学习不同层次的特征表示：

网络层次学到的特征类型具体例子（以图像为例）
浅层（靠近输入） 低级特征、边缘、纹理 线条方向、颜色对比度、简单图案
中层 中级特征、局部结构 形状轮廓、角点、纹理组合
深层（靠近输出） 高级语义、全局概念 物体部件、完整对象、场景含义
✅
Universal Approximation Theorem（万能近似定理）：理论上，一个足够宽的单层隐藏层网络可以逼近任意连续函数。但在实践中，深层网络远比宽网络高效——因为深层可以通过指数级的效率来复用中间特征表达。这就是「深度学习」之「深」的意义所在。

5 反向传播算法（Backpropagation）

神经网络拥有成千上万个参数（权重和偏置），如何高效地找到最优参数？答案就是反向传播（Backpropagation，简称 BP） + 梯度下降优化器的组合拳。

直觉理解：链式法则 + 「责任分配」

1
前向传播 Forward
输入从第一层逐层传递到最后一层，计算预测输出 y_pred
2
计算损失 Loss
比较 y_pred 与真实标签 y_true，得到损失值 L（如 MSE / CrossEntropy）
3
反向传播 Backward
利用链式法则，从输出层向回逐层计算每个参数对损失的贡献（梯度 ∂L/∂w）
4
梯度更新 Update
根据梯度和优化器规则，更新每个参数：w = w - lr × ∂L/∂w

常用优化器对比

优化器核心思想特点
SGD 纯随机梯度下降，固定学习率 简单但容易陷入局部最优、收敛慢、对学习率敏感
SGDM SGD + 动量（Momentum） 利用历史梯度方向加速收敛，减少震荡
Adam 自适应学习率 + 动量 当前最常用。自动调整各参数的学习率，收敛快且稳定，适合大多数场景
AdamW Adam + 权重衰减解耦 LLM 训练标准。解决了 Adam 中权重衰减的实现问题，被 Transformer 类模型广泛采用
💡
一句话理解反向传播：想象你在玩「传话游戏」说错了最后一个字——你需要从最后一个人开始往前追溯，找出每个人在哪里出了错，然后每个人按自己的「错误程度」修正自己的说法。链式法则就是数学上实现这种「追溯责任」的工具。

6 过拟合与正则化技术

当模型在训练集上表现很好，但在测试/新数据上表现很差时，我们称之为过拟合（Overfitting）——模型「死记硬背」了训练数据的噪声而非学到真正的规律。以下是三种最常用的正则化技术：

📤 Dropout
nn.Dropout(p=0.5)
训练时随机「丢弃」（置零）一定比例的神经元输出。迫使网络不依赖任何单一神经元，增强泛化能力。推理时关闭，所有神经元参与但输出需缩放。由 Hinton 于 2014 年提出。
📊 Batch Normalization
nn.BatchNorm1d(dim)
对每一 mini-batch 的数据进行归一化（零均值、单位方差），并引入可学习的缩放/偏移参数。加速训练、允许更大学习率、起到轻微正则化效果。几乎成为现代网络标配。
🔎 L2 正则（权重衰减）
weight_decay=0.01
在损失函数中添加权重的 L2 范数惩罚项，鼓励权重趋向较小值。限制模型复杂度，防止某个特征影响过大。是最经典、最简单的正则化手段。
✅
LLM 训练中的正则化实践：大语言模型主要依赖 Dropout（通常 p=0.1）和 AdamW 的 weight_decay 来防止过拟合。BatchNorm 在 Transformer 架构中被 LayerNorm（层归一化）取代——因为 BN 对序列长度敏感，而 LN 对每个样本独立归一化，更适合 NLP 任务。

本节总结：神经网络是 AI 的基石，感知机是其最小单元，激活函数赋予其非线性能力，多层堆叠形成强大的特征提取器，反向传播提供高效的参数学习机制，正则化技术保证泛化能力。这些基本概念将在后续的大语言模型章节中反复出现——理解了神经网络，你就理解了 LLM 的底层逻辑。
