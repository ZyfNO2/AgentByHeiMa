Core Concepts

什么是 Harness Engineering？

Harness 是一种新兴的 AI 工程范式，通过「套索」将大语言模型与外部工具、数据源和工作流紧密编织在一起，让 AI Agent 具备真正的工程化能力。

🎯

Skill 技能体系

Skill 是 Harness 的核心单元 —— 可复用、可组合的 AI 能力模块。每个 Skill 封装了特定领域的知识和操作逻辑，Agent 可以按需调用，像搭积木一样构建复杂工作流。

🤖

Agent 智能体

AI Agent 不再是简单的对话机器人，而是具备自主规划、工具调用、多步骤推理能力的智能实体。它能够理解任务目标，拆解执行路径，并协调多个 Skill 完成复杂目标。

🔗

MCP 协议层

Model Context Protocol (MCP) 是连接 AI 与外部世界的标准化接口。通过 MCP，Agent 可以无缝访问数据库、API、文件系统等资源，打破模型的能力边界。

🎬

全自动化流水线

从内容策划 → 脚本生成 → 语音合成 → 视频渲染，整条生产线由 Agent 自主驱动。人类只需提供主题方向，剩余工作全部交由 AI 完成。

Workflow

完整实战流程

从零开始，一步步搭建属于你的 AI 视频自动化生产线。

1

环境准备 / Preparation

安装 Claude Code CLI、配置 API Key、克隆 Garden Skills 仓库。确保基础运行环境就绪，这是一切自动化工作的前提条件。

$ npm install -g @anthropic-ai/claude-code
$ git clone https://github.com/ConardLi/garden-skills/
2

定义 Skill 工作流 / Define Workflow

根据视频类型选择或自定义 Skill 组合。例如「技术教程」类视频需要：Research Skill（资料搜集）→ Script Skill（脚本撰写）→ TTS Skill（语音合成）→ Render Skill（视频渲染）。

3

输入主题与约束 / Input Topic

向 Agent 描述你想要制作的视频主题、目标受众、时长要求、风格偏好。Agent 会基于这些信息进行自主规划和内容创作。

「请制作一期关于 React Server Components 的技术讲解视频，面向中级前端开发者，时长控制在10分钟左右，风格偏向简洁专业」
4

Agent 自主执行 / Auto Execution

Agent 开始自主运转：搜索资料 → 整理大纲 → 撰写详细脚本 → 分段生成语音 → 合成字幕轨道 → 渲染最终视频。整个过程无需人工干预。

5

审核与迭代 / Review & Iterate

预览生成的视频效果，如需调整可向 Agent 反馈修改意见。支持多轮对话式优化，直到产出满意的内容成品。
